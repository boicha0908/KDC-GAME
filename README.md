# KDC ARENA

Firebase 연결 버전의 실행·설정 방법은 **ONLINE-GUIDE.md**를 먼저 읽어주세요. 아래 내용은 이전 로컬 프로토타입 설명입니다.

중·고등학생이 KDC 10개 주류를 익히는 수업용 퀴즈 아레나 프로토타입입니다.

## 포함된 흐름

- 개인전 / 단체전 선택
- 카드 매칭 / 책 표지 퀴즈 선택
- 5~12문제 라운드 설정
- 최대 20명 대기실과 방 코드 표시
- 타이머, 정답 해설, 점수판, 결과 순위
- CSV 결과 저장
- 모바일 반응형 화면

## KDC 원카드 보드게임

- 개인전 2~5명 / 단체전 4~10명
- 방 코드 기반 로비와 직접 팀 선택·변경
- 80장 덱: 일반 56장 + 특수 24장
- 시작 손패 6장, 백의 자리·십의 자리 매칭
- +2/+3 누적 공격, 유턴, 스킵, 조커 분류번호 지정
- 원카드 호출 타이밍과 미호출 벌칙 1장
- 교사 관전 모드: 전체 손패 수, 현재 차례, 바닥 카드, 공격 누적, 이벤트 로그

기존 카드 매칭 화면의 선택지 카드는 숫자만 표시하도록 정리했습니다.

## 실행

`index.html`, `styles.css`, `app.js`를 같은 폴더에 두고 `index.html`을 브라우저에서 열면 됩니다.

간단한 로컬 서버를 사용할 경우:

```text
npx serve .
```

## 실제 다기기 수업 운영 전 연결할 부분

현재 버전은 수업 흐름과 플레이 화면을 검증하는 정적 프로토타입입니다. 방 코드를 여러 학생의 기기에서 입력하고 점수·대진을 실시간 공유하려면 Firebase, Supabase, Cloudflare Workers 같은 온라인 백엔드 연결이 추가로 필요합니다. 다음 단계에서 `방 생성 → 학생 입장 → 문제 배포 → 정답 제출 → 점수 브로드캐스트`를 연결하면 20명 규모의 실시간 수업용으로 확장할 수 있습니다.
