# KDC ARENA

Firebase 연결·배포·수업 운영 방법은 **ONLINE-GUIDE.md**를 읽어주세요.

중·고등학생이 KDC 10개 주류를 익히는 수업용 퀴즈 아레나 프로토타입입니다.

## 포함된 흐름

- 개인전 / 단체전 선택
- 카드 매칭 / 책 표지 퀴즈 선택
- 5~12문제 라운드 설정
- 최대 20명 대기실과 방 코드 표시
- 타이머, 정답 해설, 점수판, 결과 순위
- CSV 결과 저장
- 모바일 반응형 화면

## KDC 원카드 보드게임

- 개인전 2~5명 / 단체전 4~10명
- 방 코드 기반 로비와 직접 팀 선택·변경
- 80장 덱: 일반 56장 + 특수 24장
- 시작 손패 6장, 백의 자리·십의 자리 매칭
- +2/+3 누적 공격, 유턴, 스킵, 조커 분류번호 지정
- 원카드 호출 타이밍과 미호출 벌칙 1장
- 교사 관전 모드: 전체 손패 수, 현재 차례, 바닥 카드, 공격 누적, 이벤트 로그

기존 카드 매칭 화면의 선택지 카드는 숫자만 표시하도록 정리했습니다.

## 실행

`index.html`, `styles.css`, `app.js`를 같은 폴더에 두고 `index.html`을 브라우저에서 열면 됩니다.

간단한 로컬 서버를 사용할 경우:

```text
npx serve .
```

## 온라인 운영 안내

KDC 원카드와 실시간 퀴즈는 Firebase Realtime Database를 통해 여러 기기에서 방·참가자·게임 상태를 공유합니다. 상단의 **교사** 버튼은 온라인 교사 화면으로 이동하고, **학생 입장** 버튼은 실제 Firebase 방 코드로 접속합니다. 기본 경기 설정의 카드 매칭 퀴즈는 한 기기에서 진행하는 로컬 시연 모드입니다.

교사 화면은 별도 대시보드이며 Google 계정 로그인을 사용합니다. 학생은 익명 인증으로 방에 입장합니다. 카드매칭·책표지 로컬 게임은 기존 경기 설정에서 계속 사용할 수 있습니다. Firebase 서비스 설정과 배포 단계는 **ONLINE-GUIDE.md**를 확인하세요.
